Introdução

O que é o DropGenesis?

Motor universal de instalação, provisionamento e configuração para aplicações PHP. Qualquer aplicação compatível pode ser instalada de forma totalmente automatizada através de um manifesto e contratos de integração.

⚡
Rápido

Cache de sessão em todas as camadas. Instalação típica em menos de 30 segundos.

🧩
Modular

Arquitetura baseada em contratos. Adicione novos drivers sem modificar o core.

🌐
Multilíngue

Suporte nativo a PT-BR, EN, ES e FR. Adicione novos idiomas criando um arquivo de 50 linhas.

🔒
Seguro

Proteção CSRF, sanitização completa, sessões seguras e validação de tokens.

Objetivos

  • Instalar aplicações PHP compatíveis de forma totalmente automatizada.
  • Arquitetura modular baseada em contratos (DriverInterface).
  • Interface Web e CLI (linha de comando).
  • Internacionalização completa (i18n).
  • Documentação técnica profissional para desenvolvedores.

Benefícios da Integração

  • Elimina a necessidade de configuração manual de banco de dados e variáveis de ambiente.
  • Funciona tanto em VPS (raiz do domínio) quanto em subpastas no XAMPP.
  • Suporte a múltiplos frameworks: Laravel, CodeIgniter, Symfony, PHP Nativo e Custom.
  • Hook system completo para personalização do fluxo de instalação.
  • Compatível com hospedagens compartilhadas de baixo desempenho.

Instalação

Instalação Passo a Passo

Siga estas etapas para integrar o DropGenesis à sua aplicação PHP do zero.

  1. 1
    Download

    Baixe o pacote DropGenesis do Envato Market ou do repositório oficial e extraia o conteúdo na raiz do seu projeto.

  2. 2
    Organização das Pastas

    Certifique-se de que a pasta DropGenesis/ está na raiz do projeto, no mesmo nível do index.php principal.

  3. 3
    Configure o Manifesto (drop.json)

    Edite o arquivo DropGenesis/drop.json com os dados da sua aplicação:

    JSON
    {
  "name": "MinhaApp",
  "version": "1.0.0",
  "description": "Minha aplicação PHP incrível",
  "driver": "native",
  "requirements": {
    "php": ">=8.0",
    "extensions": ["mysqli", "curl"],
    "dirs_writable": ["storage", "config"]
  },
  "database": {
    "sql_file": "database/base.sql",
    "config_file": "config/local.php"
  }
}
  4. 4
    Prepare o Banco de Dados SQL

    Coloque o arquivo SQL inicial em database/base.sql. Este arquivo será executado automaticamente durante a instalação.

  5. 5
    Inclua o Engine no index.php raiz
    PHP
    <?php
// Autoload das classes do DropGenesis
spl_autoload_register(function (string $class): void {
    $map = [
        'DropGenesis\\Core\\'      => __DIR__ . '/DropGenesis/src/Core/',
        'DropGenesis\\Contracts\\' => __DIR__ . '/DropGenesis/src/Contracts/',
        'DropGenesis\\Drivers\\'   => __DIR__ . '/DropGenesis/src/Drivers/',
    ];
    foreach ($map as $prefix => $base) {
        if (str_starts_with($class, $prefix)) {
            $file = $base . str_replace('\\', '/', substr($class, strlen($prefix))) . '.php';
            if (is_file($file)) { require_once $file; return; }
        }
    }
});

use DropGenesis\Core\Engine;

$engine = new Engine(__DIR__);

// Helper de tradução global
if (!function_exists('__')) {
    function __(string $key, array $params = []): string {
        global $engine;
        return htmlspecialchars($engine->getTranslator()->translate($key, $params), ENT_QUOTES, 'UTF-8');
    }
}
  6. 6
    Acesse o Instalador

    Abra http://seu-dominio.com/ no navegador. O DropGenesis detecta automaticamente se a aplicação está instalada e redireciona para o wizard quando necessário.

  7. 7
    Finalização

    Após a instalação bem-sucedida, a pasta DropGenesis/ é bloqueada automaticamente por um arquivo .htaccess gerado. O instalador não fica acessível em produção.

🔄 Fluxo

Fluxo do Instalador

O instalador percorre as seguintes etapas em sequência, com validação em cada passo antes de avançar.

#EtapaDescrição Técnica
1Boas-vindasDetecção de app instalada, exibição do wizard, seleção de idioma via $_GET['lang'].
2Requisitos do ServidorEngine::checkRequirements() verifica PHP, extensões e permissões de diretórios. Resultado cacheado em sessão.
3Leitura do ManifestoManifestParser lê e valida o drop.json. JSON cacheado por mtime na sessão.
4Seleção de DriverEngine::initDriver() instancia o driver correto de acordo com o campo driver do manifesto.
5Configuração do BancoFormulário coleta host, usuário, senha e nome do banco. Validação de conexão via mysqli.
6Importação SQLNativeDriver::installDatabase() executa o base.sql via multi_query com tratamento de erro por statement.
7Migrations & SeedersExecuta arquivos SQL adicionais definidos no manifesto ou no diretório database/migrations/.
8Configuração do AmbienteNativeDriver::bootstrapApplication() escreve api/config.php e atualiza o .env em uma única passagem.
9Usuário AdministradorCriação do usuário administrador com senha criptografada via password_hash().
10FinalizaçãoDisparo de evento after_install, bloqueio do instalador e redirecionamento para a aplicação.
🔗 Integração

Como Integrar ao Projeto

Guia completo para integrar o DropGenesis a um projeto existente, passo a passo.

1. Copiar os Arquivos

Copie a pasta DropGenesis/ inteira para a raiz do seu projeto. Não altere a estrutura interna.

2. Registrar o Instalador

No index.php raiz da sua aplicação, inclua o autoloader e inicialize o Engine como mostrado na seção de Instalação.

3. Configurar Rotas

PHP
// Detectar se o app está instalado e redirecionar se necessário
$isInstalled = is_file(__DIR__ . '/api/config.php');
if (!$isInstalled) {
    header('Location: /DropGenesis/');
    exit;
}

4. Personalizar Temas e Layout

O DropGenesis usa CSS custom properties (:root) para tokens de design. Para alterar o tema, sobrescreva as variáveis no <head>:

CSS
/* Custom theme override */
:root {
  --primary:   #e11d48;   /* vermelho */
  --accent:    #f59e0b;   /* âmbar */
  --bg:        #0a0a0f;
}

5. Adicionar Novas Etapas ao Wizard

O wizard de instalação (DropGenesis/index.php) é estruturado por um array de etapas. Adicione novas etapas ao array $steps no início do arquivo com a seguinte estrutura:

PHP
$steps = [
    1 => 'license',
    2 => 'database',
    3 => 'admin',
    4 => 'minha_etapa_customizada',  // ← adicione aqui
    5 => 'finish',
];

6. Criar Validadores Personalizados

PHP
// Dentro do processamento do formulário da sua etapa:
if (empty($_POST['my_field'])) {
    $errors[] = 'Campo obrigatório não preenchido.';
}

// Avança apenas se não há erros
if (empty($errors)) {
    $_SESSION['install_step'] = $nextStep;
    header('Location: ?step=' . $nextStep);
    exit;
}

7. Adicionar Novos Módulos (Drivers)

Crie uma nova classe em DropGenesis/src/Drivers/ implementando DriverInterface:

PHP
namespace DropGenesis\Drivers;
use DropGenesis\Contracts\DriverInterface;

class LaravelDriver implements DriverInterface
{
    public function getCapabilities(): array { /* ... */ }
    public function detectDatabaseUrl(bool $isHttps): string { /* ... */ }
    public function verifyLicense(string $key, string $domain): array { /* ... */ }
    public function installDatabase(\mysqli $conn, string $sqlFile): void { /* ... */ }
    public function bootstrapApplication(array $config): void { /* ... */ }
}

// No drop.json, defina: "driver": "laravel"
// O Engine instanciará automaticamente LaravelDriver.
📚 API Reference

API do Core

Documentação de todas as classes públicas do DropGenesis com métodos, parâmetros, tipos de retorno e exemplos.

Engine

Orquestrador central. Inicializa sessão, manifesto, tradutor e dispatcher de eventos.

public__construct(string $rootPath)

Inicializa o engine com o caminho raiz da aplicação. Inicia a sessão PHP, carrega o manifesto e o translator.

publiccheckRequirements(bool $forceRefresh = false): array

Verifica PHP, extensões e diretórios graváveis definidos no drop.json. Resultado cacheado em sessão. Use $forceRefresh = true para re-checar.

publicgenerateCsrfToken(): string

Gera um token CSRF de 64 caracteres hexadecimais e o armazena na sessão. Retorna o token gerado.

publicvalidateCsrfToken(string $submitted): void

Valida o token submetido via hash_equals(). Lança RuntimeException se inválido. Rotaciona o token após validação bem-sucedida.

publiccsrfField(): string

Retorna uma string HTML com o campo hidden do CSRF pronto para inserção em formulários.

publicgetEvents(): EventDispatcher

Retorna o singleton do EventDispatcher para registro e disparo de hooks.

ManifestParser

Lê e valida o arquivo drop.json. Cache baseado em mtime do arquivo.

publicgetName(): string

Retorna o nome da aplicação definido no manifesto.

publicgetRequirements(): array

Retorna o array de requisitos: php, extensions, dirs_writable.

publicget(string $key, mixed $default = null): mixed

Acesso genérico a qualquer chave do manifesto. Útil para chaves customizadas.

Translator

Motor de internacionalização com detecção automática de idioma e cache de sessão.

publictranslate(string $key, array $replace = []): string

Retorna a string traduzida para o locale atual. Suporta substituições de placeholder: :variavel.

PHP
$engine->getTranslator()->translate('welcome_user', ['name' => 'Júnior']);
// → "Bem-vindo, Júnior!"
publicgetSupportedLocales(): array

Retorna os locales suportados: ['pt', 'en', 'es', 'fr'].

EventDispatcher

Sistema de hooks leve baseado em singleton. Suporta prioridades e interrupção de propagação.

publicon(string $event, callable $callback, int $priority = 10): void

Registra um listener. Listeners com maior prioridade executam primeiro. Retornar false interrompe a propagação.

publicfire(string $event, array $payload = []): bool

Dispara um evento. Retorna false se a propagação foi interrompida por algum listener.

publicflush(?string $event = null): void

Remove todos os listeners de um evento específico, ou de todos os eventos se null.

🎣 Hooks & Eventos

Hooks e Eventos

O sistema de hooks permite interceptar qualquer etapa do processo de instalação sem modificar o core.

Eventos Disponíveis

before_install after_install before_migration after_migration before_seed after_seed before_finish after_finish on_error

Exemplos Práticos

PHP
use DropGenesis\Core\EventDispatcher;

$dispatcher = EventDispatcher::getInstance();

// Executar lógica personalizada após a instalação
$dispatcher->on('after_install', function(array $payload): void {
    // Enviar e-mail de boas-vindas
    mail($payload['admin_email'], 'Instalação concluída!', 'Sua app está pronta.');
});

// Bloquear instalação se requisito customizado falhar
$dispatcher->on('before_install', function(array $payload): bool {
    if (!extension_loaded('imagick')) {
        // Retornar false interrompe a instalação
        return false;
    }
    return true;
}, priority: 20); // prioridade alta — executa antes de outros listeners

// Capturar erros de instalação
$dispatcher->on('on_error', function(array $payload): void {
    error_log('[DropGenesis] Erro: ' . ($payload['message'] ?? 'desconhecido'));
});
🎨 Customizações

Customizações

Guia completo de personalização do DropGenesis sem modificar o core.

Logo e Nome do Projeto

Substitua o arquivo img/logo.webp pelo logo da sua aplicação. O nome exibido no instalador é lido do campo name no drop.json.

Adicionar Novo Idioma

Crie um arquivo em DropGenesis/src/Languages/xx.php (ex: de.php para alemão) retornando um array associativo com as chaves de tradução:

PHP
<?php
// DropGenesis/src/Languages/de.php
return [
    'welcome'      => 'Willkommen',
    'welcome_desc' => 'Lassen Sie uns Ihre App in wenigen Schritten installieren.',
    'next_step'    => 'Nächster Schritt',
    // ... todas as demais chaves
];

Em seguida, adicione o locale ao array SUPPORTED na classe Translator.

Banco de Dados Customizado

Para suportar PostgreSQL ou SQLite, crie um driver personalizado implementando DriverInterface e registre-o no Engine::initDriver().

Sistema de Licenciamento

O método NativeDriver::verifyLicense() pode ser estendido para integrar com qualquer API de licenciamento. O payload esperado é {'valid': true, 'message': '...'}.

🔒 Segurança

Segurança

Práticas de segurança implementadas no DropGenesis para proteger o processo de instalação e os dados da aplicação.

RecursoImplementaçãoLocalização
Proteção CSRFEngine::generateCsrfToken() + hash_equals() para comparação segura. Token rotacionado após validação.Engine.php
Sanitização de OutputToda saída HTML passa por htmlspecialchars() via helper h() ou __().Todas as views
Sessões SegurasSessão iniciada apenas quando necessário. Dados sensíveis nunca persistidos em sessão sem limpeza.Engine.php
Bloqueio Pós-InstalaçãoGeração automática de .htaccess bloqueando acesso ao diretório DropGenesis/ após instalação.DropGenesis/index.php
Injeção SQLQueries de instalação usam arquivos SQL controlados. Credenciais escritas via var_export() com escape automático.NativeDriver.php
Criptografia de Senhaspassword_hash(PASSWORD_BCRYPT) para criação do usuário admin. password_verify() na autenticação.Formulário Admin
Timeouts de redecURL com CONNECTTIMEOUT = 3s e TIMEOUT = 6s para evitar bloqueio do processo durante validação de licença offline.NativeDriver.php
⚠ Atenção Após a instalação em produção, remova ou restrinja completamente o acesso à pasta DropGenesis/ no servidor. Nunca deixe o instalador acessível em ambiente de produção.
🔧 Troubleshooting

Solução de Problemas

ProblemaCausaSolução
Tela branca ao acessar o instaladorErro PHP não exibido. PHP < 8.0 ou extensão faltando.Ativar display_errors temporariamente. Verificar versão PHP com php -v.
Falha na conexão com o bancoCredenciais incorretas, MySQL não rodando ou porta diferente da padrão.Verificar host/usuário/senha. Testar com mysql -u user -p. Em XAMPP, usar 127.0.0.1 ao invés de localhost.
Pasta não gravávelPermissões de filesystem incorretas no servidor.Executar chmod 775 storage config ou ajustar via cPanel. Em VPS, verificar usuário do Apache/Nginx.
Instalador acessível após instalação.htaccess de bloqueio não foi gerado ou Apache não processa .htaccess.Verificar se AllowOverride All está no VirtualHost. Criar manualmente o .htaccess com Deny from all.
Erro de CSRF token inválidoSessão PHP expirou ou cookie de sessão não enviado.Aumentar session.gc_maxlifetime no php.ini. Verificar configurações de cookie no servidor.
Idioma não muda após seleçãoCache de sessão de traduções antigo. Arquivo de idioma não encontrado.Limpar sessão via session_destroy() em debug. Verificar se o arquivo Languages/xx.php existe e retorna um array.
